Sistema de Evaluación de Riesgo Crediticio para Inmobiliaria

Cómo usarlo: Copie cada bloque de código (desde @startuml hasta @enduml) y péguelo en el editor de PlantUML (https://www.plantuml.com/plantuml) o en la extensión de PlantUML de VS Code.
Criterio aplicado (include vs extend):
<<include>> = comportamiento OBLIGATORIO, siempre se ejecuta (el CU está incompleto sin él).
<<extend>> = comportamiento OPCIONAL o CONDICIONAL, solo se dispara bajo ciertas condiciones.

CU-01 — Iniciar sesión (con 2FA)

Actores: Propietario, Administrador, Operador  ·  Dependencias: RF-07, RNF-03, RNF-04, RNF-05

@startuml
left to right direction

actor Propietario as PROP
actor Administrador as ADMIN
actor Operador as OPER

rectangle "Sistema de Evaluacion de Riesgo Crediticio" {
    usecase "Iniciar sesion" as CU01
    usecase "Validar credenciales" as V1
    usecase "Solicitar codigo 2FA (OTP)" as V2
    usecase "Denegar acceso" as V3
}

PROP --> CU01
ADMIN --> CU01
OPER --> CU01

CU01 ..> V1 : <>
V2 ..> CU01 : <>
V3 ..> CU01 : <>

note bottom of V2
  Se dispara solo si la cuenta
  tiene 2FA activo.
end note

note bottom of V3
  Se dispara tras varios
  intentos fallidos.
end note

@enduml
